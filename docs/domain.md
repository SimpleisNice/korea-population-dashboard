# 서비스 도메인 정의

> 작성: 2026-07-09 · 갱신: 2026-08-18 (원천 CSV 형식 교체 반영)
> 목적: "이 서비스가 무엇이고 무엇이 아닌지"를 명확히 하여, 기능 제안·우선순위 판단의 기준선으로 삼는다.

---

## 1. 도메인 한 줄 정의

**"시군구 인구 변동을 단순하게 읽어주는, 부동산·상권 판단 도구"**

행정안전부 주민등록 인구통계를 가공해 **인구가 늘고 있는지 줄고 있는지를 직관적으로 전달**하고, 그 흐름을 부동산 구매·이주·창업 판단의 참고로 쓰게 하는 서비스다. 실시간 API, 예측 모델, 개인 식별 데이터를 다루지 않는다.

**두 축을 혼동하지 않는다.**
1. **지금 하는 것** — 인구 변동을 쉽게 보여준다. 이게 제품의 본체다.
2. **발전 방향** — 그 위에 부동산·장사 판단 레이어를 얹는다. 1이 정확하고 단순해진 다음의 일이다.

> 용어 주의: "실거주 인구"가 아니라 **주민등록 인구**다. 등록 주소지 기준이라 실제 거주·유동 인구와 다르다 — `/methodology`에 고지되어 있다.

## 2. 포지셔닝: KOSIS가 비워둔 칸

경쟁 대상은 통계청 KOSIS **[인구로 보는 대한민국](https://kosis.kr/visual/populationKorea/PopulationDashBoardMain.do)**이다. 벤치마킹 결론은 `docs/benchmark-kosis.md`에 있고, 요지는 셋이다.

| | KOSIS 인구상황판 | 이 서비스 |
|---|---|---|
| 지역 해상도 | 전국 + **17개 시도까지** | **시군구 230개** (+ 일반구 39) |
| 지표 수 | 50개 이상 나열 | 소수의 핵심 지표 + 해석 |
| 답하는 질문 | "인구 구조가 어떤가" | "**여기 사도 되나 / 장사해도 되나**" |

- **KOSIS를 이길 수 없는 영역:** 지표 가짓수, 장래추계, 출생·사망·혼인 등 인구동향 원자료. 확장하지 않는다.
- **KOSIS가 못 하는 영역:** 시군구 해상도, 그리고 "그래서 어쩌라는 것인가"에 대한 답. 여기에 집중한다.

**핵심 가정:** 인구 증감은 주거 수요·상권 활성도·지역 개발 가능성의 선행/동행 지표다.

**인접 도메인 경계**
- 부동산 실거래가·시세 ❌ 다루지 않음
- 유동인구·매출·상권 분석 데이터 ❌ 보유하지 않음. 주민등록은 거주지 기준이라 상권을 직접 말하지 못한다. 상권 관련 서술은 **거주 인구 구조에서 추론 가능한 범위**로 제한한다
- 인구 예측/추계 ⚠️ 6개월 선형 추세 연장일 뿐 공식 추계가 아니다. KOSIS 장래추계(~2072년)와 경쟁하지 않는다
- 거시 인구 통계(전국·광역) △ 시군구 수치를 읽기 위한 기준선 역할까지만

## 3. 하위 도메인 (기능 축)

`BottomNav` 4탭과 대체로 일치한다.

| 하위 도메인 | 답하는 질문 | 핵심 페이지 |
|---|---|---|
| **지역 프로파일링** | "이 동네 인구가 어떻게 변해왔는가?" | `/[sido]/[sigungu]`, `/[sido]/[sigungu]/detail` |
| **전국 랭킹/탐색** | "어디가 뜨고 어디가 빠지는가?" | `/ranking`, `/trending`, `/map` |
| **상대 비교** | "A와 B 중 어디가 나은가?" | `/compare` |
| **개인화 탐색** | "관심 있는 곳만 다시 보고 싶다" | 홈의 즐겨찾기·최근 본 지역 (localStorage, 서버 저장 없음) |

## 4. 데이터 도메인 경계

**단위:** 10자리 MOIS 코드. 다만 현재 데이터셋은 계층이 섞여 있다.

| 계층 | 개수 | 상태 |
|---|---|---|
| 현행 최상위 시군구 | 230 | `level: 'sigungu'` — 합계·순위의 기준 집합 |
| 일반구 (수원시 장안구 등) | 39 | `level: 'district'` — 검색·비교·상세에서는 유지, 합계·순위에서만 제외 |
| 폐지 지역 | 3 | `retiredAfter` — 2026.07 인천 분할로 폐지. 이력 조회만 가능 |

계층 혼재는 2026-08-10 P0에서 해소했다(`Region.level` + `getTopLevelRegions()`). 읍면동(하위)과 시도 단독 분석(상위)은 부차적으로만 지원한다.

**개편은 상수가 아니라 변수다.** 2023.06 강원, 2023.07 군위군, 2024.01 전북, 2024.01 부천시 일반구 부활, 2026.02 화성시 일반구 신설, 2026.07 광주+전남 통합·인천 분할 — 3년 반 동안 6번이다. 지역 수와 시도명을 문구나 코드에 고정하지 않는다(`principles.md` A4-2·B1).

**지표 종류:** 총인구·세대수·세대당 인구·성비·연령 구조(10세 단위)·순이동 근사치. 소득·주택가격·산업 통계는 도메인 밖.

**시간 해상도:** 월 단위. 주민등록 통계 자체가 월 공표이므로 일/주 단위와 실시간성은 구조적으로 불가.

**보유 범위:** **2023.01~2026.07(43개월)**, 인구·세대·연령 동일. 총 272개 지역.

연령 데이터가 인구 데이터보다 한 달 뒤처지는 달이 있는 것은 MOIS 공표 일정상 정상이며, `getRegionDetail`이 가장 가까운 이전 월로 대체한다.

**갱신 방식:** 수동. `data/raw/`에 CSV 추가 → `npm run check-raw` → `npm run build-data` → 커밋 → 배포. 자동 크롤링·API 연동 없음(백로그 M-4).

**원천 형식 변경과 행정구역 개편은 상시 리스크다.** 2026-08 한 번에 둘 다 겪었다 — MOIS 다운로드 형식이 바뀌어 파서가 한 파일도 못 읽었고(`spec.md` D14), 동시에 2026.07 개편 2건(광주+전남 통합, 인천 분할)이 들어와 있었다. 갱신 절차에 **"`check-raw`를 먼저 돌리고, `build-data` 출력의 지역 수·최신월·합계 대조를 확인한다"**를 포함한다.

## 5. 사용자 정의

| 페르소나 | 니즈 | 주 사용 도메인 |
|---|---|---|
| 내 집 마련 실수요자 | 후보 지역의 인구 추세·연령 구조 확인 | 지역 프로파일링, 비교 |
| 갭투자·임장 리서처 | 여러 지역 빠른 스캔·스크리닝 | 랭킹, 트렌딩, 지도 |
| 이주 검토자(비부동산) | 인구 감소·고령화 여부 확인 | 지역 프로파일링 |
| **창업·자영업 검토자** *(발전 방향)* | 상권 후보지의 배후 인구 규모·연령대·1인 가구 비중 확인 | 지역 프로파일링, 비교 |

**창업 페르소나에 대한 솔직한 한계:** 우리 데이터는 거주 인구이지 유동 인구가 아니다. 상권의 실제 매출력은 말하지 못한다. 답할 수 있는 것은 "배후 거주 인구가 늘고 있는가", "주 연령대가 무엇인가", "1인 가구 비중이 높은가"까지다. 이 선을 넘는 서술을 쓰지 않는다.

## 6. 도메인 밖 (현재 기준)

- 회원가입·로그인, 서버 사이드 개인화 저장
- 실시간 데이터, 외부 API 런타임 연동
- AI 기반 해설 생성 (백로그 M-2)
- 유료 리포트·구독 (백로그 M-3)
- 데스크톱 최적화 레이아웃, 다크 모드 (의도적으로 유지하지 않음)

---

## 7. 신규 기능 판단 기준

순서대로 통과해야 한다. 하나라도 걸리면 만들지 않는다.

1. **단순함** — 화면에 지표를 늘리지 않고 되는가? 늘려야 한다면 뺄 것을 함께 정했는가? (`docs/principles.md` 0-1)
2. **판단 가능성** — "이 값이 크면/작으면 사용자는 무엇을 다르게 하는가"에 한 문장으로 답할 수 있는가?
3. **KOSIS 비교 우위** — 시군구 해상도를 살리는가? 거시 지표 확장이면 탈락 (`docs/principles.md` 0-2)
4. **데이터 가용성** — 보유 CSV로 되는가? 새 외부 데이터가 필요하면 도메인 확장 논의가 먼저다
5. **집계 정합성** — 계층 혼재(§4) 위에 새 왜곡을 얹지 않는가? (`docs/principles.md` A1)

---

**정리:** 이 서비스는 "인구 통계 서비스"가 아니라 **"인구 변동을 부동산·장사 판단으로 번역해주는 렌즈"**다. 통계를 더 많이 보여주는 방향이 아니라, 같은 통계에서 더 분명한 판단을 뽑아내는 방향으로 발전한다.
