## 2-1. AdSense 정책 위반 대응 (2026-08-11)

**증상:** 승인은 되었으나 정책 위반 경고가 반복.

**구조적 원인:** `adsbygoogle.js`가 루트 레이아웃에서 전 페이지에 로드되고 있었다. 대시보드에서 자동 광고(Auto Ads)가 켜져 있으면 Google이 `/map`(419자)·`/compare` 빈 상태(559자)·지역 상세처럼 얇은 화면에 광고를 자동 삽입 → "게시자 콘텐츠가 없는 화면" 위반. 사람의 대시보드 설정에 의존하는 방어라 반복될 수밖에 없었다.

**조치**

| | 내용 |
|---|---|
| 스크립트 범위 축소 | `adsbygoogle.js`를 `layout.tsx`에서 제거하고 `AdSlot` 안으로 이동. 광고 유닛이 렌더되는 홈·`/ranking`·`/trending`에만 스크립트가 존재 → **자동 광고가 켜져 있어도 다른 화면에 삽입 불가** |
| 홈 콘텐츠 보강 | 563자 → **1,130자**. 실제 수치에서 파생되는 "이번 달 인구 흐름 요약"(전국 총인구·최대 증가/감소 지역·고령화 최고 지역) + 주민등록 인구의 한계 면책 문구 |
| 지역 수 동적 렌더 | "226개" 하드코딩 제거 (P1-2) |

**남은 확인 사항 (사용자 직접)**

1. AdSense 대시보드에서 **자동 광고 OFF** — 코드로 차단했지만 설정도 맞추는 것이 안전하다
2. 위반 항목의 **정확한 문구와 대상 URL** 확인 — 위 조치로 안 잡히는 다른 원인이 있을 수 있다
3. `*.vercel.app` 서브도메인 — 당분간 유지로 결정. 위반이 계속되면 이쪽을 의심

### 2026-08-11 재진단 — 자동 광고는 원인이 아니었다

대시보드 실제 상태: **승인 상태 "주의 필요" / 상태 세부정보 "가치가 별로 없는 콘텐츠" / Ads.txt "찾을 수 없음"** (최종 업데이트 2026-07-19).

정책 위반이 아니라 **사이트 심사 반려**다. 위의 자동 광고 차단은 유효한 위생 조치였지만 이 문제의 해결책은 아니었다.

**원인 ①: 가치가 별로 없는 콘텐츠**

7월 10일에 이미 `RegionAnalysis` 서술과 `/methodology`를 추가했는데도 7월 19일 심사에서 같은 판정을 받았다. 문장 몇 개로는 넘지 못한다. 구조 문제다 — sitemap 543개 URL 중 536개(98.7%)가 숫자만 다른 동일 템플릿이었다.

**원인 ②: Ads.txt 찾을 수 없음**

파일 자체는 정상이다(`korea-population-dashboard.vercel.app/ads.txt` → 200). 다만 루트 도메인 `vercel.app/ads.txt`는 Vercel 홈페이지로 리다이렉트된다. 구글이 루트에서 찾고 있거나, 미승인 상태라 아직 크롤링하지 않았을 수 있다. **커스텀 도메인이 확실한 해법이지만 비용 문제로 보류 결정(2026-08-11).**

**조치 (2026-08-11)**

## 4. P3 — 신규 서비스 후보

도메인 §7 필터(단순함 → 판단 가능성 → KOSIS 비교 우위 → 데이터 가용성 → 집계 정합성)를 통과한 것만.

**핵심 제약 2가지**
1. 이 저장소에는 인구·세대·연령 3종 외의 데이터가 없다.
2. **지표를 늘리는 방향은 KOSIS와 겹친다.** 아래 후보는 모두 "새 지표"가 아니라 "보유 데이터에서 판단을 뽑는" 쪽이어야 한다.

## 5. 권장 실행 순서

```
✅ P0-1~5  →  ✅ P1-1~4·6  →  ✅ N-6 한 줄 판정  →  ✅ P0-7 파서 재작성 (+ P1-7)
✅ P1-5 탭 통합  →  ✅ P1-8 lint  →  ✅ N-5 월간 리포트  →  ✅ N-2 세대 분화
🔵 배포(push)  →  AdSense 심사 재요청  →  P2
```

**P0·P1 전부 완료. N-5 완료 (2026-08-19).**

**AdSense 심사 재요청이 다음인 이유:** "심사 재요청은 준비가 끝난 뒤 한 번에"로 결정해 두었고(2026-08-11), 그 준비가 이제 끝났다. 남은 두 항목은 **사용자 직접 조치**다.

| | 상태 |
|---|---|
| 콘텐츠 깊이 | 리포트 42장 신설. sitemap 550 → **593 URL**, 그중 43장이 에디토리얼 |
| 자동 광고 OFF | 코드로는 구조적 차단 완료. 대시보드 설정 확인 필요 |
| ads.txt "찾을 수 없음" | 파일은 200. 커스텀 도메인은 비용 문제로 보류 중 — 재요청 후에도 같은 판정이면 이쪽이 원인 |

**N-2 는 2026-08-19 완료.** 지표 자체는 이미 있었고 비교 수단이 없었던 것이라, `/ranking` 정렬 추가로 끝났다.

**그 다음은 P2(UX).** P2-1(트렌딩·상세 기간을 URL로)이 원칙 C2 위반 2곳을 정리한다.
- **N-5를 P2보다 앞에 올렸다.** AdSense 심사 반려의 근본 원인이 "sitemap의 98.7%가 동일 템플릿"이므로, 템플릿이 아닌 콘텐츠를 늘리는 유일한 경로다. P2는 UX 개선이라 심사를 움직이지 못한다.
- 이후 N-2(세대 분화). 추가 데이터가 필요 없고 KOSIS에 없는 고유 지표다.

**이력 근거 (완료분)**
- P0 없이는 홈 화면 첫 숫자가 20% 틀린 채로 남았다. 신규 기능보다 우선했다.
- P1-1을 P0 직후에 둔 이유: 같은 결함이 재발하지 않게 고정하기 위함. 나중에 붙이면 의미가 반감된다.
- **N-6을 P2보다 앞에 둔 이유:** 제품 방향(`domain.md` §1 — 인구 변동을 부동산·장사 판단으로 번역)에 가장 가까우면서 비용이 가장 낮았다. 새 데이터도 새 지표도 없이 기존 `RegionAnalysis`를 재구성하는 일이었다. 2026-08-11 완료.

**이번 사고의 교훈:** 원천 데이터 형식은 우리가 통제하지 못한다(원칙 A5). 갱신 절차가 "파일을 넣는다"에서 끝나면 이번처럼 조용히 깨진다. `check-raw`와 파서 단위 테스트가 P0-7에 포함된 이유다.
