## 4. P3 — 신규 서비스 후보

도메인 §7 필터(단순함 → 판단 가능성 → KOSIS 비교 우위 → 데이터 가용성 → 집계 정합성)를 통과한 것만.

**핵심 제약 2가지**
1. 이 저장소에는 인구·세대·연령 3종 외의 데이터가 없다.
2. **지표를 늘리는 방향은 KOSIS와 겹친다.** 아래 후보는 모두 "새 지표"가 아니라 "보유 데이터에서 판단을 뽑는" 쪽이어야 한다.

### 보유 데이터로 즉시 가능

| ID | 후보 | 내용 | 가치 |
|---|---|---|---|
| **N-1** | **인구 구조 유사 지역 추천** | 연령 분포 + 세대당 인구 + 성비를 벡터로 삼아 코사인 유사도 상위 5개 지역 제시. "○○구와 인구 구조가 닮은 곳" | 비교 페이지의 지역 선택 진입 장벽을 없앤다. 추가 데이터 0 |
| **N-2** | **세대 분화 지표** | 인구 증감과 세대수 증감의 괴리를 지표화. 인구는 주는데 세대는 느는 지역 = 1인 가구 전환 진행 → 소형 주거 수요 신호 | 이미 두 시계열을 다 갖고 있는데 조합한 적이 없다. 이 서비스만의 고유 지표가 될 수 있다 |
| **N-3** | **증감의 성별 분해** | 미사용 CSV(`*_other_population_change_monthly.csv`)를 파싱해 월별 증감을 남·여로 분리. 특정 연령·성별 유출 패턴 관측 | 파일이 이미 저장소에 있다. 파서 하나 추가로 끝 |
| **N-4** | **연령 코호트 추적** | 같은 코호트를 시간축으로 따라가 유출입 추정(2023년 20대 → 2026년 20대 후반). 청년 유출 지역 식별 | 연령 39개월치를 보유. 이동자 통계 없이 근사 가능한 유일한 방법 |
| **N-5** | **월간 리포트 페이지** | 최신월 데이터가 들어올 때마다 `/report/2026-04` 같은 정적 페이지 자동 생성. 그 달의 급증·급감·특이 지역 요약 | SEO 신규 랜딩 + AdSense 콘텐츠 깊이. 데이터 갱신이 곧 콘텐츠 생산이 된다 |
| **N-6** | **한 줄 판정 (제품 방향의 핵심)** | 지역 페이지 최상단에 인구 추세·연령 구조·세대 분화를 종합한 **한 문장 판정**을 놓는다. 예: "인구 증가, 30~40대 유입 중 — 주거 수요 확대 구간" | 도메인 §7 필터 1·2번을 정면으로 만족. 지표를 늘리지 않고 판단을 준다. 부동산·장사 레이어의 출발점이 된다 |

**N-6이 왜 중요한가:** KOSIS는 지표 50개를 주고 해석은 사용자에게 맡긴다(`benchmark-kosis.md` ②). 우리가 그 반대를 하면 겹치지 않는다. 현재 `RegionAnalysis`가 3문단 서술을 생성하고 있는데, 이를 **맨 위 한 문장 + 근거**로 재구성하는 것이 N-6이다. 새 데이터도, 새 지표도 필요 없다.

### 새 데이터가 필요

| ID | 후보 | 필요한 것 | 판단 |
|---|---|---|---|
| **N-7** | 실제 전입·전출 분석 | KOSIS 국내인구이동통계 | 도메인 적합성 높음. "어디서 와서 어디로 가는가"는 현재 근사로 답하지 못하는 질문 |
| **N-8** | 읍면동 단위 세분화 | MOIS 읍면동 CSV | **KOSIS와 가장 멀어지는 방향**이라 차별점은 크다. 다만 데이터량이 시군구의 약 15배 — 요청마다 파일을 읽는 현재 구조로는 감당 어려워 저장 전략부터 재설계 필요 |

## 5. 권장 실행 순서

```
P0 (1~6 일괄)  →  P1-1 테스트로 고정  →  P1-2~6  →  N-6 한 줄 판정  →  P2  →  N-2 / N-5
```

**근거**
- P0 없이는 홈 화면 첫 숫자가 20% 틀린 채로 남는다. 신규 기능보다 우선한다.
- P0-6(5세 단위 재다운로드)을 함께 하는 이유: 다음 달 CSV를 받기 전에 정해야 갱신 절차에 반영된다.
- P1-1을 P0 직후에 두는 이유: 같은 결함이 재발하지 않게 고정하기 위함. 나중에 붙이면 의미가 반감된다.
- **N-6을 P2보다 앞에 둔 이유:** 제품 방향(`domain.md` §1 — 인구 변동을 부동산·장사 판단으로 번역)에 가장 가까우면서 비용이 가장 낮다. 새 데이터도 새 지표도 없이 기존 `RegionAnalysis`를 재구성하는 일이다.
- 이후 신규는 **N-2(세대 분화)**와 **N-5(월간 리포트)**. 둘 다 추가 데이터가 필요 없고, N-2는 KOSIS에 없는 고유 지표를, N-5는 AdSense 콘텐츠 깊이와 SEO 유입을 동시에 만든다.
